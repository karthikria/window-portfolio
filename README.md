# 🖥️ Windows Portfolio

A creative and interactive personal portfolio designed to provide a Windows desktop experience directly in the browser.

Instead of a traditional portfolio layout, this project recreates a desktop environment where visitors can explore my profile, projects, technical skills, education, and contact information through an interactive interface.

🌐 **Live Demo:** https://riaroy.netlify.app/  
💻 **GitHub Repository:** https://github.com/karthikria/window-portfolio

---

## ✨ About the Project

This portfolio is built to showcase my technical skills, projects, and learning journey through a modern Windows-inspired desktop interface.

The main idea is to make portfolio exploration more interactive and engaging by allowing visitors to open different applications and explore information inside desktop-style windows.

It combines a familiar desktop experience with a personal portfolio to create something different from a traditional website.

---

## 🚀 Features

- 🖥️ **Windows-Inspired Desktop UI** – A desktop environment inspired by the Windows operating system.
- 📂 **Interactive Application Windows** – Explore different sections through desktop application icons.
- 📌 **Taskbar Interface** – Navigate between available portfolio applications.
- 👨‍💻 **About Me** – Learn about my background, interests, and career goals.
- 💼 **Projects Showcase** – Explore my development projects and technical work.
- 🛠️ **Skills Section** – Discover my programming languages, frameworks, and tools.
- 🎓 **Education Section** – View my academic background.
- ⚙️ **Settings Interface** – Explore the portfolio's settings window.
- 💻 **Terminal Interface** – Experience a developer-inspired terminal environment.
- 📱 **Responsive Design** – Designed to provide a smooth experience across different screen sizes.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/karthikria/window-portfolio.git
```

### 2. Navigate to the Project Folder

```bash
cd window-portfolio
```

### 3. Open the Project

Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.
